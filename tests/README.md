# Локальный интерфейс проверки

Фронтенд находится в `tests/frontend`: HTML, CSS и JavaScript без сборки,
внешних библиотек и npm-зависимостей. Существующий frontend Игоря не менялся.
Страницы отдаёт тестовый FastAPI; отдельный веб-сервер не нужен.

Из корня `alfa-insight`:

```bash
./tests/start.sh
```

Открыть **http://127.0.0.1:8001/tests/**. Swagger остаётся на `/docs`.
Если стенд уже работает, просто открой страницу. Для перезапуска:

```bash
./tests/start.sh stop
./tests/start.sh
```

`./tests/start.sh offline` запускает бесплатную OfflineLLM;
`./tests/start.sh check` выполняет локальные проверки;
`./tests/start.sh down` останавливает сервер и PostgreSQL с сохранением данных.
Полные настройки backend описаны в `backend/app/test/README.md`.

## Сценарий

1. Выбери компанию из списка (поиск по ID или отрасли), имя и роль сотрудника.
2. Откроется окно новостей. «Вся лента» показывает каталог Игоря;
   «Для компании» отбирает новости по результатам персонального ранжирования.
3. Выбери новость. Её полный текст загрузится из API Игоря, затем автоматически
   запустится анализ выбранной пары company/news. Готовый результат используется
   из кеша; повторной платной генерации при попадании в кеш нет.
4. Изучи факты, релевантность, позицию банка, интерпретацию AI, риски,
   возможности и следующие проверки. Номера цитат ведут к источникам справа.
5. Задай вопрос в чате или нажми готовую подсказку для своей роли.
6. «Шаги агента» показывают журнал; «Диагностика» — безопасные метрики LLM
   и публичный ответ API. При сбое остаются текст ошибки и кнопка повтора.

Роль и имя — демонстрационный контекст в localStorage. Авторизация и права
сотрудников не реализуются и не имитируются. Роль выбирает подсказки в чате;
аналитика backend по контракту зависит от компании и новости, а не роли.

Режим живой LLM виден в шапке. Выбор новости без готового кеша, отправка
вопроса и явная кнопка «Обновить анализ» используют квоту API. Загрузка
каталога, фильтрация и просмотр сохранённого анализа её не расходуют.
Кнопка «Обновить анализ» посылает `force_refresh=true`; обычный выбор — false.

Ссылку `?insight=<id>` можно открыть повторно: восстановятся сохранённый анализ,
компания, новость и история чата без вызова модели. Имя/роль берутся из браузера.
Свой текст можно добавить через раскрывающуюся форму в окне новостей.

Условия из вопроса чата, например количество станков, могут отображаться
отдельной цитатой «По вашим словам»; это информация пользователя. Она не
считается подтверждённой новостью или позицией банка. При нарушении проверки
ответа допускается одно исправление моделью; это может расходовать ещё один
вызов. Отсутствие подходящей банковской аналитики отображается в готовом
анализе как «позиция не найдена».

## API

| Действие | Маршрут |
|---|---|
| Список/профиль компаний | Существующие `/api/companies` и `/api/companies/{id}` Игоря |
| Каталог/текст новостей | Оригинальный `app.news.router`, подключённый в стенде как `/igor/api/news/catalog` и `/igor/api/news/{id}` |
| Персональный подбор | `/api/news?company_id=...` |
| Анализ/чат/история/trace | `/api/insights/...` |
| Новый текст новости | `/api/news/manual` |
| Состояние/диагностика | `/health`, `/api/debug/llm` |

Префикс `/igor` позволяет вызывать готовые обработчики новостей Игоря без
конфликта с тестовыми DTO. Его код, SQL и основной frontend не меняются.
Все запросы идут на тот же localhost, поэтому ключ LLM не попадает в браузер
и настройка CORS не требуется.
