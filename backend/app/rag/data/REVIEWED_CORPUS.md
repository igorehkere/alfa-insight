# Проверенный корпус для передачи

`reviewed_corpus.json` содержит 10 выбранных выдержек из трёх предоставленных
аналитических PDF. Сверка выполнена по изображениям первых физических страниц
24.10.2026; OCR использовался как черновик. Неправильные символы OCR исправлены
по изображению, таблицы и графики в эти выдержки не включены.

| Документ | Дата | Страница PDF | Выдержки |
|---|---|---|---|
| ALFA-Macro_Insights-Policy_Rate_11Sep.pdf | 11.09.2026 | 1 | 3: решение по ставке, риски предложения, прогноз банка |
| Inflation_tracker_02.pdf | 02.09.2026 | 1 | 4: инфляция, бензин, рубль, риск роста цен на топливо |
| ALFA-7M26.pdf | 07.09.2026 | 1 | 3: потребление, автомобили, финансовые результаты компаний |

Исходные файлы находятся в `analitics/` проекта. SHA-256 каждого оригинала,
число страниц, название, дата и стабильные ID выдержек сохранены в JSON.
URL отсутствуют: публичные ссылки не придумывались. Номера страниц отсчитываются
от 1 в оригинальном PDF. Документы исторические; их прогнозы не подтверждают
последующие решения регулятора или сегодняшние условия кредита.

Это проверенная выборка для MVP, не полный постраничный импорт всех материалов.
Небольшой `bank_corpus.json` оставлен как прежняя однодокументная тестовая фикстура.
Для рабочего индекса импортируйте именно `reviewed_corpus.json`.

Для расширения корпуса запустите `python -m app.rag.ingest --help`.
Импорт PDF создаёт непроверенные фрагменты; страницы с изображениями требуют OCR
и языковых данных rus+eng. Сопоставьте извлечённый текст с оригиналом, особенно
числа, даты, отрицания и колонки. Только затем подтверждайте страницы через
`python -m app.rag.review ... --confirm-reviewed` и повторяйте индексацию.
Нельзя автоматически помечать весь OCR-корпус проверенным.

Команда `index-bank` заменяет банковскую часть индекса содержимым переданного JSON.
Чтобы сохранить прежние документы, сначала объедините их в один корпус.
Индекс новостей при этом сохраняется.
